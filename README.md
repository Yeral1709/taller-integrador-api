# Taller Integrador de APIs con PHP

## Descripción
Aplicación desarrollada durante el Técnico en Programación de Software (SENA), integrando consumo de APIs externas mediante cURL en PHP y interfaces dinámicas con HTML, CSS y JavaScript.

## Objetivo
Demostrar el flujo completo de desarrollo de software utilizando control de versiones con Git y GitHub, aplicando buenas prácticas y consumo de servicios web.

## Tecnologías
- HTML5 / CSS3
- JavaScript
- PHP (con funciones cURL)
- APIs Externas (Dog CEO, Open Library, JSONPlaceholder)
- Git y GitHub

## Funcionalidades
- Consultar imágenes aleatorias de perros por raza.
- Buscar libros utilizando la API de Open Library.
- Consultar y enviar posts de prueba mediante solicitudes GET y POST a JSONPlaceholder.

## Ejecución
1. Clonar el repositorio.
2. Ubicar la carpeta dentro de `htdocs` en XAMPP.
3. Iniciar el servicio de Apache.
4. Abrir la aplicación desde `http://localhost/nombre-de-tu-carpeta/index.php`.
