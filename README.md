# Taller Integrador de APIs con PHP

## Descripción
Aplicación desarrollada durante el Técnico en Programación de Software (SENA), integrando consumo de APIs externas mediante cURL en PHP y una interfaz moderna con HTML5 y CSS3.

## Objetivo
Demostrar el flujo completo de desarrollo de software utilizando control de versiones con Git y GitHub, aplicando buenas prácticas, manejo de ramas (feature, fix), Pull Requests e Issues.

## Tecnologías Utilizadas
- HTML5 / CSS3 (con variables personalizadas)
- JavaScript
- PHP 8 (con funciones cURL para peticiones GET y POST)
- APIs Externas: Dog CEO (Perros), Open Library (Libros), JSONPlaceholder (Posts)
- Git y GitHub

## Flujo de Funcionamiento de la Aplicación
1. **Usuario** interactúa con el formulario en la interfaz HTML.
2. **JavaScript / PHP** procesan la solicitud del usuario.
3. Se ejecuta la petición HTTP mediante **cURL** hacia la API correspondiente.
4. La API retorna una respuesta en formato **JSON**.
5. El sistema procesa los datos y renderiza la interfaz visual con los resultados o maneja el error de forma controlada.

## Ejecución Local
1. Clonar este repositorio.
2. Ubicar la carpeta del proyecto dentro del directorio `htdocs` de XAMPP.
3. Iniciar el servicio de Apache.
4. Abrir la aplicación en el navegador ingresando a: `http://localhost/nombre-de-tu-carpeta/index.php`.
